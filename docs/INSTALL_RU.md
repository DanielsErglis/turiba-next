# TURĪBA NEXT — установка и настройка

Версия: 1.0.0-rc.4. Это кандидат на релиз: работа на реальном iPhone ещё должна быть подтверждена. TURĪBA NEXT — независимый студенческий проект, не связанный с администрацией Turība.

## Установка

1. Установите Scriptable по ссылке с [официального сайта](https://scriptable.app/).
2. Передайте файл `TURIBA NEXT.js` из установочного комплекта на iPhone, например через AirDrop в «Файлы». Node.js и остальные файлы репозитория на телефоне не нужны.
3. Откройте меню «Поделиться» у JavaScript-файла и выберите Scriptable, если этот вариант доступен. Сохраните скрипт под именем `TURIBA NEXT`.
4. Если импорт через «Поделиться» недоступен: откройте файл как текст, скопируйте всё содержимое, создайте скрипт кнопкой `+` в Scriptable, вставьте текст и задайте имя `TURIBA NEXT`. Изменять код не требуется.
5. Запустите скрипт в приложении Scriptable. При первом запуске выберите язык и введите свой код группы из публичного расписания, например `TVL2D1`. Это только пример — программа поддерживает другие группы каталога.
6. Откройте «Факультативы и подгруппы» и выберите только свои варианты. Невыбранные варианты не считаются обязательными. Индивидуальные сведения BATIS могут отсутствовать в публичном расписании.
7. При необходимости выберите системное, светлое или тёмное оформление. Уведомления изначально выключены; виджет работает без них.

Пароль BATIS, Apple ID, контакты, фотографии и геолокация программе не нужны. При сетевой ошибке не вводите университетские учётные данные: проверьте доступность публичного расписания.

## Добавление виджета

1. На домашнем экране iPhone удерживайте свободное место и откройте добавление виджетов. Названия пунктов зависят от версии iOS.
2. Найдите Scriptable и добавьте Small или Medium.
3. Удерживайте добавленный виджет, откройте его редактирование и выберите скрипт `TURIBA NEXT`.
4. Поле Parameter оставьте пустым для основной группы. Для другого экземпляра можно ввести отдельный код группы, например `CSA1D1`.
5. Если настройка действия при нажатии доступна, выберите запуск скрипта. Нажатие на виджет открывает настройки.

Параметр виджета не меняет основную группу. Напоминания относятся только к основной группе. Темы и язык общие; выбранные курсы сохраняются отдельно для групп. Чтобы настроить факультативы дополнительной группы, временно выберите её основной, настройте варианты и затем верните прежнюю группу. При смене основной группы её старые напоминания удаляются.

Время занятий всегда относится к Europe/Riga, в том числе при поездках в другой часовой пояс. Дата рядом со временем помогает отличить следующее занятие в другой день. Текущая пара остаётся на экране до окончания. Пометка о сохранённых/устаревших данных означает, что актуальность нужно проверить.

## Обновление расписания

Откройте скрипт и выберите «Обновить сейчас». Виджет также запрашивает обновление средствами Scriptable. iOS самостоятельно определяет фактическое время обновления; переход статуса ровно за десять минут не гарантируется.

Если неделя не опубликована или источник не подтверждён, это не означает, что занятий нет. Последнее корректное расписание сохраняется. При отсутствии аудитории программа прямо указывает, что она не предоставлена.

## Необязательные напоминания

В настройках откройте «Напоминания о занятиях», включите их и выберите 10 минут (вариант по умолчанию), 5, 15 или 30 минут. iOS может запросить разрешение, когда появится первое подходящее занятие для планирования. Если таких занятий пока нет, фиктивное уведомление для запроса разрешения не создаётся.

При отказе виджет продолжит работать. Разрешение можно проверить в настройках уведомлений Scriptable на iPhone. Выключение напоминаний удаляет ожидающие напоминания проекта. Уведомления других скриптов не удаляются.

Напоминания планируются максимум на семь дней вперёд, до 32 за один план. Уточняйте расписание регулярной синхронизацией. Изменение на университетском сайте становится известно программе только после следующей успешной загрузки. При недоступном источнике ранее созданное напоминание может устареть.

## Apple Shortcuts — дополнительная возможность

Автоматизация на реальном устройстве ещё не проверена и не является обязательной для работы виджета.

1. В «Командах» создайте команду с действием Scriptable для запуска `TURIBA NEXT`.
2. Передайте в параметр запуска текст `sync`. Он запускает синхронизацию без меню настроек.
3. Сначала запустите команду вручную и проверьте результат. `ok` означает отсутствие обнаруженной ошибки; `setupRequired` означает, что сначала нужно выбрать группу. Код ошибки требует проверки источника/настроек.
4. Только после успешной ручной проверки создайте личные автоматизации на 07:00, 12:00 и/или 20:00 с запуском этой команды. Подтвердите работу каждой на своём iPhone.

Эти часы — предложенные настройки. Возможности запуска без подтверждения и ограничения фонового выполнения зависят от iOS. Автоматизация здесь не создаётся и не объявляется проверенной.

## Обновление программы

1. Получите новую версию файла из доверенного комплекта владельца проекта.
2. Замените содержимое существующего скрипта `TURIBA NEXT`, сохранив его имя. Не требуется создавать второй скрипт или удалять данные.
3. Запустите скрипт, проверьте настройки, нажмите «Обновить сейчас» и проверьте оба виджета.
4. Сравните SHA-256 с `SHA256SUMS`, если проверяете целостность на Mac. Не запускайте код неизвестного происхождения.

Локальные настройки и кеш хранятся отдельно от текста скрипта. Если будущая версия меняет формат данных, следуйте её инструкции миграции; не считайте сброс обязательным для каждого обновления.

## Удаление данных

В меню выберите «Удалить мои данные» и подтвердите удаление. Будут удалены настройки, выбор группы, кеш и ожидающие напоминания TURĪBA NEXT. Скрипт останется и вернётся к выбору группы. Данные и уведомления других проектов сохраняются.

После установки выполните проверки из `IPHONE_CHECKLIST.md`. До их подтверждения кандидат не считается полностью проверенной версией 1.0.

## Если ошибка появляется после выбора языка

Для повторной проверки используйте rc.4: замените содержимое существующего скрипта, сохранив имя. Данные удалять не нужно. При повторной ошибке на экране появятся Build, Stage, Code, Message и, при наличии, Cause. Передайте эти строки владельцу проекта. Диагностика остаётся на телефоне и автоматически никуда не отправляется. Пока повторная проверка не выполнена, причина исходного сбоя не считается установленной.
