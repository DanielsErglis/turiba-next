# TURĪBA NEXT — Android: установка и проверка

Это независимый студенческий проект. Версия 0.1.0-rc.2 предназначена для частного тестирования; обязательные проверки на физических телефонах ещё не завершены. Android 10 или новее. Scriptable не требуется.

1. Получите APK непосредственно у владельца проекта. Сравните SHA-256 с `RELEASE.json`. Откройте файл, временно разрешите установку из этого источника, установите приложение и затем отключите это разрешение. APK не опубликован в магазине.
2. Откройте TURĪBA NEXT, выберите System/LV/EN/RU, введите код группы и нажмите «Проверить и сохранить группу». Требуется интернет. Если источник недоступен, повторите позже; приложение не придумывает расписание.
3. Явно отметьте свои дисциплины по выбору и подгруппы. Неотмеченные альтернативы не становятся обязательными автоматически. Названия предметов сохраняются на языке источника.
4. В меню виджетов домашнего экрана добавьте квадратный или прямоугольный TURĪBA NEXT. Новый экземпляр использует сохранённую основную группу без повторного ввода. Если основной группы ещё нет, откроется настройка. Через перенастройку виджета можно выбрать другую группу. Группы экземпляров независимы. Масштабируйте виджет средствами лаунчера. Нажатие открывает соответствующий экземпляр; кнопка обновления запускает ручную синхронизацию.
5. Выберите системную, светлую или тёмную тему. Изменение темы и языка использует локальные данные. Время расписания и последней синхронизации всегда относится к Europe/Riga.

Уведомления изначально выключены. Включайте их только по своему желанию: на Android 13+ приложение запросит разрешение. Выберите 5/10/15/30 минут. Напоминания относятся только к основной группе, выбранным подтверждённым занятиям. Android может задерживать их; после начала занятия просроченное напоминание подавляется. Точного будильника и постоянной фоновой службы нет. Отказ в разрешении не мешает расписанию. После принудительной остановки откройте приложение снова. Не считайте это единственным средством контроля времени занятий.

При отсутствии сети сохраняется последнее корректное расписание с предупреждениями. Неопубликованная неделя не означает отсутствие занятий. Проверяйте отметки устаревания, неполноты и необходимости выбора, дату и время последней успешной синхронизации. Отсутствующая аудитория отображается явно. Обновите вручную и при необходимости сверьтесь с публичным сайтом университета. Для `UNSAFE_REDIRECT`/изменения структуры не обходите проверку безопасности: передайте владельцу код ошибки, версию и модель телефона без персональных данных.

Данные хранятся во внутренней памяти приложения; резервное копирование в облако и перенос настроек отключены. Нет аккаунтов, аналитики, рекламы, собственного сервера или удалённых журналов. Сеть приложения обращается только по HTTPS к nodarbibas.turiba.lv. Локальное хранилище не заявлено как зашифрованное. «Удалить мои данные» с подтверждением удаляет настройки, выбор, кэш и напоминания, отменяет собственные фоновые задания и возвращает виджеты к настройке. Данные других приложений не затрагиваются.

Для обновления установите APK с тем же идентификатором и подписью поверх существующего, без удаления приложения. Перед проверкой смены версии запишите выбранную группу и тему, после обновления убедитесь, что они сохранены. Если подпись отличается, остановитесь и получите правильный APK; удаление приложения сотрёт данные.

Физическая приёмка: Pixel, Samsung и Xiaomi. Для каждого запишите модель, Android/оболочку, лаунчер, версию APK, настройки батареи; проверьте оба виджета, независимые группы, размеры/шрифт, языки/темы, офлайн, уведомления OFF/ON/отказ, перезагрузку, обновление и удаление. Оставьте телефон на ночь без открытия приложения и измерьте задержки обновления/напоминаний, расход батареи и трафика. Результаты записывайте по форме `DEVICE_ACCEPTANCE.md`; успешный эмулятор не заменяет эти проверки.

Во второй тестовой версии целевые размеры — 2×2 и 4×2. Фактические размеры зависят от сетки лаунчера. После обновления старый виджет может сохранить область 2×3/4×3: уменьшите его либо удалите только виджет с рабочего стола и добавьте заново. Приложение не удаляйте — его настройки сохранятся. На самых маленьких карточках предупреждения сокращены: «Сеть» — нет сети, «Кэш» — устаревшие данные, «Выб» — нужен выбор занятий, «?» — неделя не подтверждена. Полные пояснения доступны в приложении и средствах доступности.
