# Android architecture decision — 2026-11-04

Status: chosen design within the owner's requested native stack; dependency resolution/build verification pending toolchain provisioning. No alternate framework or architecture approval is required.

## Modules and dependencies

- `:core`: pure Kotlin/JVM. Strict non-executing HTML tree/tokenizer, catalog/time-grid/schedule parser, typed errors, immutable domain models, explicit Riga calendar/time, choices, state engine, reminder plan. No android.*, UI, storage or network imports. No HTML auto-repair library needed: port the constrained proven tokenizer.
- `:app`: Android adapter packages for source, storage, settings, localization/theme, app UI, widgets, background and reminders. Compose observes repository state; UI never fetches directly. Glance translates immutable widget models into RemoteViews. Use responsive supported sizes rather than fixed iPhone dimensions.
- Shared evidence: `../tests/fixtures/raw` and manifest, never packaged in application assets. Android parity corpus records normalized expected results generated by existing JS from these exact fixtures, plus separately labeled synthetic state/time/error cases. Preserve source evidence and JS files unchanged.

Repository flow: bounded exact-host HTTPS transport → strict parser/validated week → Room transaction → pure selection/state engine → Compose/Glance. A failure updates error/sync metadata while preserving the last published valid week. Unknown group is catalog-based, not echoed heading/HTTP 200. An unpublished/empty table is not a free week. Catalog TTL 24h, verified fallback up to seven days; timetable throttle 15m, manual bypass. Sunday requests actual server week, preserving cached calendar week; negative navigation is not used to invent history.

## Storage, synchronization and deletion

Room separates catalog entries, validated week envelopes/lessons, sync markers, widget-instance mappings, reminder registry and a deletion generation. DataStore holds primary group, language/theme, opt-in lead and per-group explicit choices. Version schemas; export Room schemas and test migrations before upgrades. Internal app-only files; disable backup and cloud/device transfer explicitly for app data. No key or university account required.

Application-scoped repository serializes mutations. Network requests run outside the lock but capture the current deletion generation; a write transaction rejects results after generation changes. Cancellation plus generation checks are both required. Delete increments generation under the same lock, persists reset settings, cancels owned workers/alarms/notifications, clears project rows/service files and updates all installed widgets to setup. Widget identities can be enumerated from AppWidgetManager after local settings reset; they must not revive old groups. No worker may infer a configured group after reset.

Unique group/week sync work coalesces requests across instances. Keep normal bounded network timeouts, cap body size, validate scheme/host/userinfo/port via URI/URL, reject all redirects, rely on platform TLS. No remote scripts/resources execute. Current/next requests validate actual returned dates before caching. Apply capped retries/backoff for transient errors only. A theme/locale change recalculates local presentation without download.

## Time and reminders

Use java.time ZoneId Europe/Riga and valid-offset enumeration. Zero offsets = gap; two offsets = error unless caller explicitly selects earlier/later. Calendar date arithmetic, not fixed 24h, defines midnight/week. State ordering must use documented deterministic tie-breaking and preserve concurrent lessons. Choice key is the exact compact JSON pair [sourceGroup,subject], with explicit UTF-16/Unicode and JSON parity fixtures; no casual string concatenation.

OFF short-circuits before permission APIs, registry enumeration, planning or scheduling. Explicit ON requests POST_NOTIFICATIONS on applicable Android versions and checks current permission again before delivery. Baseline delivery uses scoped immutable PendingIntents and inexact alarms with visible possible-delay text. Do not declare USE_EXACT_ALARM. Investigate an optional SCHEDULE_EXACT_ALARM mode only if justified by acceptance; do not silently promise exact timing. Registry entries carry stable identity/fingerprint/week and prevent hash collisions/duplicates. Only main-group verified fresh selected non-provisional lessons can plan. Unverified weeks cannot establish cancellation; delivery revalidates settings/generation/freshness and safely suppresses obsolete intents.

Boot/package-replaced/time-change receivers may enqueue local reconciliation only when configured/enabled. Permission revocation is checked on resume and receiver entry. Force-stop suppresses background delivery until user launches again; document it. WorkManager handles deferrable network work with connectivity constraint; local widget state updates are separate best-effort work around boundaries and never trigger network solely for status changes. No permanent foreground service. Periodic minimum/flex/Doze limitations are not exact refresh guarantees.

## Widgets and interface

Two provider variants for square and rectangular, responsive to available dp sizes. Separate room panel on rectangular, next-lesson footer with time, large subject, blue/cyan, system font, accessible contrast and missing-room/uncertainty flags. No unofficial-project footer. Main screen and configuration activity share validated group/choice flows; appWidgetId has independent saved group. Reconfiguration/cancel/deletion/restoration must be transactional. Explicit matching PendingIntent identifiers prevent one instance opening another group's screen. Manual update is clear; clicks resolve current mapping rather than trusting stale extras.

About/Privacy retains independent-project provenance. System/LV/EN/RU and System/Light/Dark use complete resources; official subject names remain source text. Display last successful sync separately from last attempt. Do not hide selection/coverage/offline/stale indicators behind an otherwise correct current lesson.

## Toolchain and versions

Plan minSdk 29: native java.time is available, satisfying all requested libraries' minimum levels. Target/compile API 37 (Android 17) pending actual stable SDK installation. Official SDK catalog names API 37 packages `platforms;android-37.0`/`.1`/`.2`, so do not assume the historical `platforms;android-37` package ID.

Candidate AGP 9.4.0 + Gradle 9.6.0 + JDK 17 follows the [official compatibility table](https://developer.android.com/build/releases/agp-9-4-0-release-notes). Use AGP built-in Kotlin according to its actual resolved dependency; match the Compose compiler plugin to that Kotlin version. Confirm KSP compatibility through resolution/compilation before final pinning. Lock exact versions and dependency verification in the implementation phase; no dynamic `+` dependencies.
