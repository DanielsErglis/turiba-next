TURĪBA NEXT — установка на iPhone с нуля

Здесь всё, что нужно для установки: один скрипт и подробная инструкция. Компьютер и навыки программирования не нужны.

Что вы устанавливаете

TURĪBA NEXT показывает расписание группы Turība на домашнем экране iPhone. Есть квадратный и прямоугольный виджеты. Можно выбрать русский, английский или латышский язык, светлую или тёмную тему. Напоминания о занятиях необязательны и изначально выключены.

Scriptable — приложение, внутри которого работает этот виджет. Оно должно остаться установленным. Скрипт — файл с готовой программой. Его не нужно понимать или исправлять: достаточно добавить в Scriptable и выбрать свою группу.

Подготовьте:

  • iPhone с интернетом;
  • приложение Scriptable;
  • архив TURIBA-NEXT-iPhone.zip или отдельный файл TURIBA NEXT.js;
  • код вашей учебной группы, например TVL2D1. Это пример, а не обязательная группа для всех.

Названия кнопок могут немного различаться в зависимости от языка и версии iOS. В инструкции русские названия сопровождаются английскими там, где это полезно.

Шаг 1. Установите Scriptable

  1. На iPhone откройте Scriptable в App Store. Если ссылка не открывается, откройте App Store вручную и найдите Scriptable. Разработчик — Simon B. Støvring.
  2. Нажмите «Загрузить» / Get или значок облака, если уже устанавливали приложение.
  3. Если App Store просит подтвердить загрузку через Face ID, Touch ID или обычным способом вашего телефона, подтвердите её как при установке других приложений.
  4. Дождитесь окончания установки и нажмите «Открыть» / Open.
  5. Если появятся приветственные экраны Scriptable, закончите первоначальное знакомство с приложением. Примеры чужих скриптов запускать не нужно.
  6. Теперь можно вернуться к этой инструкции.

Результат: Scriptable установлен и открывается. Покупать дополнительные инструменты для TURĪBA NEXT или подключать университетский аккаунт не требуется.

Шаг 2. Сохраните комплект на iPhone

Выберите один вариант — А или Б.

Вариант А. Вы скачиваете с GitHub

  1. Откройте эту страницу в Safari на iPhone. Если открыли ссылку во встроенном окошке мессенджера, найдите «Открыть в Safari» — обычно этот пункт находится в меню с тремя точками или в меню «Поделиться».
  2. Если GitHub просит войти, используйте свой аккаунт с доступом к этому репозиторию. Если доступа нет, воспользуйтесь вариантом Б: попросите владельца прислать архив.
  3. Нажмите большую ссылку «Скачать комплект для iPhone» в начале инструкции.
  4. Если Safari спросит, хотите ли вы загрузить файл, нажмите «Загрузить» / Download.
  5. Если вместо загрузки открылась страница файла на GitHub, найдите стрелку вниз Download raw file рядом с меню файла. Она может быть внутри меню …. Нажмите её. Не выбирайте Code → Download ZIP на главной странице репозитория: это скачает весь проект, который для установки не нужен.
  6. Откройте приложение «Файлы» / Files. Его значок выглядит как папка. Если не находите приложение, проведите пальцем вниз по домашнему экрану и в поиске напишите «Файлы».
  7. Во «Файлах» откройте вкладку «Обзор» / Browse. Найдите папку «Загрузки» / Downloads. Она может находиться в iCloud Drive или в разделе «На iPhone» / On My iPhone — это зависит от ваших настроек Safari.
  8. Найдите TURIBA-NEXT-iPhone.zip. Если скачивали несколько раз, к имени может добавиться число. Возьмите последнюю загруженную копию.

Результат: архив виден в приложении «Файлы».

Вариант Б. Архив прислали в мессенджере или через AirDrop

  1. Скачайте полученный файл-архив, а не картинку и не ссылку на закрытый GitHub. Имя файла: TURIBA-NEXT-iPhone.zip.
  2. Откройте меню «Поделиться». Обычно это значок квадрата со стрелкой вверх. В мессенджере сначала может потребоваться открыть меню … у файла.
  3. Нажмите «Сохранить в Файлы» / Save to Files.
  4. Выберите удобную папку, например «На iPhone» → «Загрузки», и нажмите «Сохранить» / Save. Если папки «Загрузки» нет, можно выбрать другую — главное запомнить её.
  5. Если архив получен через AirDrop и iPhone сразу предлагает открыть или сохранить его, сохраните в «Файлы». Поведение окна зависит от версии iOS.
  6. Откройте приложение «Файлы» и ту папку, которую выбрали.

Результат: архив виден во «Файлах». Входить в GitHub не нужно.

Шаг 3. Распакуйте архив

  1. В приложении «Файлы» один раз нажмите на TURIBA-NEXT-iPhone.zip.
  2. Рядом должна появиться обычная папка с именем TURIBA-NEXT-iPhone. Если на телефоне уже была такая папка, iOS может добавить число к имени.
  3. Откройте появившуюся папку.
  4. Внутри находятся файл виджета и инструкции на трёх языках:
ФайлДля чего он нужен
TURIBA NEXT.jsСам виджет. Только этот файл добавляется в Scriptable.
INSTALL.htmlУдобная инструкция для телефона. Откройте её и выберите «Русский», «Latviešu» или «English».
INSTALL_RU.mdПолная русская инструкция обычным текстом, если HTML-просмотр недоступен.
INSTALL_LV.mdПолная инструкция на латышском языке.
INSTALL_EN.mdПолная инструкция на английском языке.
README.mdНачальная страница со ссылками на языки и скачивание.

Если вместо папки iPhone показывает содержимое архива в режиме просмотра, вернитесь в приложение «Файлы» и нажмите на сам ZIP там. Резервный вариант — удерживайте архив и выберите «Распаковать» / Uncompress, если такой пункт предлагается.

Если вам прислали только TURIBA NEXT.js, распаковывать ничего не нужно: переходите к шагу 4.

Результат: вы нашли файл TURIBA NEXT.js. Не открывайте ZIP как программу в Scriptable: сначала нужен именно файл .js из папки.

Шаг 4. Добавьте готовый скрипт в Scriptable

Сначала попробуйте способ А. Если iPhone не предлагает импорт, используйте способ Б — для него не требуется разбираться в коде.

Способ А. Через «Поделиться»

  1. Во «Файлах» нажмите и удерживайте TURIBA NEXT.js.
  2. В появившемся меню выберите «Поделиться» / Share.
  3. Посмотрите ряд значков приложений. Найдите Scriptable. Если его не видно, прокрутите ряд вправо и откройте «Ещё» / More.
  4. Выберите Scriptable. Если приложение предлагает добавить, сохранить или импортировать скрипт, подтвердите действие.
  5. Назовите скрипт TURIBA NEXT. Используйте одно и то же имя далее при выборе скрипта для виджета.
  6. Если вместо импорта показан список других скриптов, нужный скрипт не появился или Scriptable отсутствует в меню, вернитесь к инструкции и выполните способ Б. Не запускайте случайный скрипт из списка.
  7. Откройте Scriptable. На экране Scripts должна появиться отдельная карточка TURIBA NEXT.

Импорт через меню «Поделиться» зависит от версии iOS и Scriptable, поэтому отсутствие такого пункта не мешает установке.

Способ Б. Скопировать готовый текст целиком

Здесь вы просто переносите готовую программу в приложение. Ничего писать или менять в ней не нужно.

  1. Откройте файл INSTALL.html из полученной папки. Прокрутите до раздела «Код / Kods / Script text» в конце инструкции и раскройте его.
  2. Внутри есть отдельное поле с полным текстом программы. Нажмите и удерживайте текст, выберите «Выбрать всё» / Select All, затем «Скопировать» / Copy. Копируйте содержимое поля целиком, а не эту инструкцию и не заголовок раздела.
  3. Если HTML-файл не открывается или его просмотр не позволяет выделить текст, откройте сам TURIBA NEXT.js как текст и попробуйте «Выбрать всё» → «Скопировать». Ещё один вариант для тех, у кого есть доступ к GitHub: открыть страницу файла .js, нажать Raw и скопировать весь текст оттуда. Если ничего из этого не получается, попросите владельца помочь именно с переносом файла — код исправлять не требуется.
  4. Откройте Scriptable и экран Scripts.
  5. Нажмите + в правом верхнем углу. Откроется редактор нового скрипта — большое поле для текста программы.
  6. Если в поле уже есть текст, нажмите и удерживайте его, выберите «Выбрать всё», затем «Вставить» / Paste. Если поле пустое, нажмите на него и выберите «Вставить».
  7. Если iOS спросит, разрешить ли вставку из другого приложения, подтвердите вставку. Это перенос текста, который вы только что скопировали.
  8. После вставки появится много строк. Это нормально. Не удаляйте отдельные строки, не добавляйте кавычки и не вставляйте перед программой название или пояснения.
  9. Откройте настройки имени скрипта: нажмите на его название в верхней части редактора; в некоторых версиях Scriptable нужно открыть меню или настройки рядом с названием. Если видите отдельное поле имени Name, измените именно его. Не вписывайте название в сам текст программы.
  10. Задайте имя TURIBA NEXT. Нажмите Done / «Готово», чтобы выйти из редактора. Если приложение показывает отдельное подтверждение сохранения, подтвердите его.
  11. Вернитесь к списку Scripts и убедитесь, что карточка TURIBA NEXT появилась. Название Untitled Script означает, что скрипт ещё не переименован; его можно переименовать в настройках скрипта.

Результат: в Scriptable есть один скрипт TURIBA NEXT с полным содержимым файла. Сам файл .js не должен оказаться только текстовой заметкой — его код должен находиться в редакторе Scriptable.

Шаг 5. Запустите скрипт и выберите свою группу

  1. На экране Scripts нажмите на карточку TURIBA NEXT. Если открыт редактор, используйте кнопку запуска — треугольник ▶.
  2. При первом запуске появится выбор языка. Для русских названий кнопок выберите «Русский». Если выбрали другой язык, это не ошибка: язык можно изменить позже в настройках.
  3. В следующем окне нажмите на поле группы. Введите свой код, например TVL2D1.
  4. В примере используются латинские буквы T V L, цифра 2, латинская D и цифра 1. Введите код без кавычек, без слова «группа» и без пробелов внутри. Удобнее включить английскую клавиатуру.
  5. Если ваша группа другая, вводите её код. Узнать его можно у старосты, в своих учебных материалах или в публичном расписании Turība. Не выбирайте TVL2D1 только потому, что этот пример есть в инструкции.
  6. Нажмите «Сохранить» / Save и дождитесь загрузки. Не закрывайте приложение во время первоначальной загрузки.
  7. После успешной настройки появится меню TURĪBA NEXT с вашей группой. Если неделя ещё не опубликована, программа может сообщить об этом. Такое сообщение не означает, что занятий точно нет.
  8. Откройте «Факультативы и подгруппы» / Electives & subgroups, если этот пункт нужен вашей группе.
  9. Выбирайте только те курсы и подгруппы, в которых вы действительно учитесь. Галочка ✓ означает выбранный вариант; повторное нажатие снимает выбор. Для выхода нажмите «Отмена» / Cancel — уже сделанные изменения сохраняются.
  10. Если программа сообщает, что вариантов пока нет, это означает, что они не найдены в загруженных неделях. Не нужно выбирать что-то случайное. Индивидуальная информация BATIS может отсутствовать в публичном расписании.
  11. При желании откройте «Оформление» / Appearance: «Системное» следует светлой/тёмной теме телефона; «Светлое» или «Тёмное» закрепляет выбранный режим.
  12. Напоминания пока можно оставить выключенными. Для отображения расписания они не нужны.

Результат: программа знает вашу группу, язык и нужные учебные варианты. Пароль BATIS вводить не нужно.

Шаг 6. Добавьте виджет на домашний экран

Настройка скрипта и добавление виджета — разные действия. Если вы видите программу только внутри Scriptable, виджет ещё нужно добавить отдельно.

  1. Выйдите на домашний экран iPhone, где находятся значки приложений. Для начала не используйте экран блокировки.
  2. Нажмите и удерживайте пустое место между значками, пока значки не начнут покачиваться.
  3. Нажмите «Изменить» / Edit, затем «Добавить виджет» / Add Widget. В других версиях iOS вместо «Изменить» сразу показана кнопка + — нажмите её.
  4. В поиске виджетов введите Scriptable, а не TURIBA NEXT. Виджет принадлежит приложению Scriptable.
  5. Откройте Scriptable в результатах поиска.
  6. Листайте варианты размера влево или вправо:
  • Small — маленький квадрат: предмет, крупный номер аудитории и время начала;
  • Medium — прямоугольник: предмет, отдельный блок аудитории, время и следующее занятие.
  1. Выберите Small или Medium. Большой размер Large и виджеты экрана блокировки для этого комплекта не предназначены.
  2. Нажмите «Добавить виджет» / Add Widget, затем «Готово» / Done.
  3. Теперь нажмите и удерживайте сам добавленный виджет.
  4. Выберите «Изменить виджет» / Edit Widget.
  5. Найдите поле Script / «Скрипт» и нажмите на него.
  6. В списке выберите TURIBA NEXT. Здесь нужен именно скрипт, который вы добавили в шаге 4, а не один из примеров Scriptable.
  7. Поле Parameter / «Параметр» при первой установке оставьте пустым: группа уже сохранена в программе.
  8. Если есть настройка When Interacting / «При нажатии», выберите Run Script / «Запустить скрипт».
  9. Нажмите вне окна редактирования, чтобы закрыть его. Дайте iPhone немного времени показать расписание.
  10. Если хотите оба размера, повторите эти действия и добавьте второй виджет. В обоих выберите тот же скрипт TURIBA NEXT.

Результат: на домашнем экране показан ваш предмет и аудитория, а в Medium — ещё и следующее занятие. Если виджет предлагает выбрать скрипт, повторите пункты 9–12.

Шаг 7. Проверьте, что всё получилось

Откройте публичное расписание для той же группы и той же недели и сравните:

  • название предмета;
  • дату — следующее занятие может быть не сегодня;
  • время начала и окончания;
  • аудиторию. Если источник её не сообщил, программа не придумывает номер.

Время в виджете относится к Риге (Europe/Riga). Если вы сейчас за границей, это всё равно рижское время занятий.

Если сейчас занятий нет или текущая пара закончилась, виджет может показывать следующее известное занятие или соответствующий статус. Сообщение о неопубликованном/недоступном расписании не равнозначно выходному дню.

На этом обязательная установка закончена. Scriptable можно закрыть, но не удаляйте приложение: без него виджет перестанет работать.

Как потом открывать настройки

Откройте Scriptable → нажмите TURIBA NEXT. При настроенном действии нажатие на виджет тоже открывает программу.

В меню можно изменить группу, язык, оформление, учебные варианты и напоминания. Пункт «Обновить сейчас» / Sync now вручную запрашивает актуальное расписание. Когда изменения вносятся на сайте университета, виджет узнаёт о них только после следующей успешной загрузки.

Как включить напоминания — по желанию

Если достаточно расписания на экране, этот раздел можно пропустить.

  1. Откройте Scriptable → TURIBA NEXT.
  2. Выберите «Напоминания о занятиях» / Class reminders.
  3. Выберите «Вкл.» / On.
  4. Выберите, за сколько минут напоминать: 10 — стандартный вариант, также доступны 5, 15 и 30.
  5. Если iPhone запросит разрешение на уведомления Scriptable, выберите разрешение, если хотите получать напоминания.
  6. Если подходящего будущего занятия ещё нет, запроса разрешения может пока не быть: программа не создаёт фиктивное уведомление только ради этого окна.
  7. Для отключения снова откройте этот раздел и выберите «Выкл.» / Off. Ожидающие напоминания TURĪBA NEXT будут удалены; уведомления других скриптов не затрагиваются.

Ko jūs uzstādāt

Scriptable ir lietotne no App Store. TURIBA NEXT.js ir gatavs šīs lietotnes skripts, kas parāda Turības publiskā nodarbību saraksta informāciju. Logrīks ir informācijas kartīte iPhone sākuma ekrānā. Vajadzīgs iPhone ar Scriptable atbalstītu iOS versiju, interneta savienojums sākotnējai iestatīšanai un savas studiju grupas kods. Piemērs ir TVL2D1; izmantojiet savu kodu, ja mācāties citā grupā. Universitātes parole, BATIS konts, dators un programmēšana nav vajadzīgi. Lietotne nav pieejama Android ierīcēm.

Izvēļņu nosaukumi var atšķirties atkarībā no iOS un tālruņa valodas. Tālāk norādīti arī angļu nosaukumi, pēc kuriem orientēties. Ja kāda poga nav redzama, izlasiet norādīto alternatīvu.

1. solis. Uzstādiet Scriptable

  1. iPhone tālrunī atveriet Scriptable lapu App Store. Varat arī atvērt App Store un meklēt Scriptable.
  2. Pārbaudiet, ka lietotnes nosaukums ir Scriptable, izstrādātājs — Simon B. Støvring.

Ja lietotni nevar uzstādīt, apskatiet App Store norādīto iOS prasību vai pieejamo vietu tālrunī. Turpmākie soļi ir paredzēti iPhone ar strādājošu Scriptable.

  9. Atgādinājumi sākumā ir izslēgti. Lai tikai lietotu logrīku, paziņojumu atļauja nav vajadzīga. Ieslēdziet tos tikai pēc savas vēlēšanās.

Ja datu avots nav publicējis grafiku vai grupa nav atrodama, nepārpublicēts saraksts nenozīmē brīvdienu. Pārbaudiet kodu un oficiālo avotu. Programma neizdomā trūkstošās nodarbības vai kabinetus.

6. solis. Pievienojiet logrīku sākuma ekrānam

Vispirms izpildiet pirmo palaišanu Scriptable lietotnē. Tikai pēc tam pievienojiet logrīku.

  1. Atgriezieties iPhone sākuma ekrānā, kur redzamas lietotņu ikonas.
  2. Paturiet pirkstu tukšā ekrāna vietā, līdz ikonas sāk kustēties.
  3. Nospiediet Edit → Add Widget. Citās iOS versijās ekrāna augšā uzreiz ir poga +.
  4. Logrīku meklēšanā ievadiet Scriptable un izvēlieties šo lietotni.
  5. Pārvelciet priekšskatījumus, lai izvēlētos Small — mazo kvadrātveida — vai Medium — plato taisnstūrveida — logrīku. Šim projektam paredzēti šie divi izmēri.
  6. Nospiediet Add Widget, novietojiet logrīku vajadzīgajā vietā un nospiediet Done.
  7. Ja logrīks vēl nerāda grafiku, paturiet uz tā pirkstu un izvēlieties Edit Widget. Ja tas ir logrīku kaudzē, vispirms atveriet kaudzes rediģēšanu un izvēlieties attiecīgo Scriptable logrīku.
  8. Laukā Script izvēlieties TURIBA NEXT. Tas ir svarīgi: ar Scriptable logrīka pievienošanu vien nepietiek — tam jānorāda skripts.
  9. Lauku Parameter pirmajai uzstādīšanai atstājiet tukšu. Tad tiks izmantota 5. solī saglabātā galvenā grupa.
  10. Ja ir lauks When Interacting, varat izvēlēties Run Script, lai pieskāriens atvērtu skripta darbību.
  11. Pieskarieties ārpus iestatījumu lodziņa un sagaidiet atjaunošanos. Ja nepieciešams, vēlreiz palaidiet skriptu Scriptable lietotnē un atgriezieties sākuma ekrānā.

Varat pievienot gan mazo, gan plato logrīku. Abiem atsevišķi jāizvēlas TURIBA NEXT. iOS pats nosaka logrīku atjaunošanas laiku; atjaunošanās precīzi katru minūti netiek garantēta.

7. solis. Pārbaudiet, vai viss rāda pareizi

  1. Atveriet publisko Turības nodarbību sarakstu un atrodiet savu grupu un attiecīgo nedēļu.
  2. Salīdziniet nodarbības nosaukumu, datumu, sākuma/beigu laiku un kabinetu. Laiki programmā tiek interpretēti pēc Rīgas laika, arī pārejā uz vasaras/ziemas laiku.
  3. Mazajā logrīkā lielākais ciparu/burtu apzīmējums ir kabinets. Platajā logrīkā kabinetam ir atsevišķa kartīte; apakšā var būt nākamā nodarbība un tās sākuma laiks.
  4. Ja līdz tuvākajai nodarbībai ir vairākas dienas, pārbaudiet parādīto datumu. Tā nav obligāti šodienas nodarbība.
  5. Pārbaudiet arī savas izvēles kursu un apakšgrupas atlases.

Ja avotā nav norādīts kabinets vai grafiks vēl nav publicēts, programma nevar šo informāciju uzzināt. Kļūmes gadījumā pēdējais derīgais grafiks tiek saglabāts; pievērsiet uzmanību novecojušu/beztīkla datu norādei.

Ikdienas lietošana un iestatījumi

Lai atvērtu iestatījumus, palaidiet TURIBA NEXT lietotnē Scriptable. Atkarībā no logrīka mijiedarbības iestatījuma arī pieskāriens logrīkam var palaist skriptu.

  • Studiju grupa — maina galveno saglabāto grupu.
  • Valoda — maina saskarnes valodu.
  • Izskats — sistēmas, gaišā vai tumšā tēma.
  • Izvēles kursi un apakšgrupas — ļauj pārskatīt atlases.
  • Atjaunināt tagad — mēģina no jauna ielādēt grafiku, ja ir internets.
  • Nodarbību atgādinājumi — brīvprātīgi vietējie paziņojumi.
  • Dzēst manus datus — izdzēš projekta iestatījumus un kešatmiņu. Šī nav atjaunināšanas darbība; pēc tās grupa būs jāiestata no jauna.

Ja vēlaties atgādinājumus

  1. Atveriet skripta iestatījumos Nodarbību atgādinājumi.
  2. Ieslēdziet tos un izvēlieties piedāvāto atgādinājuma laiku pirms nodarbības.
  3. Ja iOS jautā paziņojumu atļauju, atļaujiet to tikai tad, ja vēlaties saņemt šos atgādinājumus.
  4. Ja agrāk atļauju noraidījāt, pārbaudiet iPhone Settings → Notifications → Scriptable vai Scriptable paziņojumu iestatījumus savā iOS versijā. Focus un klusuma režīmi arī var ietekmēt redzamību.
  5. Lai pārtrauktu projekta atgādinājumus, izslēdziet tos pašā TURIBA NEXT. Tie attiecas tikai uz galveno grupu; papildu logrīka grupa nekļūst par atgādinājumu grupu.

Atgādinājumu plāns aptver ne vairāk kā septiņas dienas un 32 atgādinājumus vienā plānā. Ja nav piemērotas nākotnes nodarbības, atļaujas jautājums var vēl neparādīties.

Paziņojumu piegādes precizitāti kontrolē iOS. Programma nevar garantēt precīzu logrīka atjaunošanu vai atgādinājuma parādīšanos jebkuros apstākļos.

Vairākas grupas vienā tālrunī

Parastai uzstādīšanai Parameter atstājiet tukšu. Ja apzināti vēlaties otru grupu, pievienojiet vēl vienu Scriptable logrīku, izvēlieties to pašu skriptu un šī logrīka Parameter laukā ierakstiet citas grupas kodu. Tas nemaina galveno grupu vai tās atgādinājumus. Ja otrai grupai vajadzīgas kursu/apakšgrupu izvēles, īslaicīgi izvēlieties to kā galveno grupu, konfigurējiet atlases un pēc tam atjaunojiet savu iepriekšējo galveno grupu. Mainot galveno grupu, tās iepriekšējie gaidošie atgādinājumi tiek noņemti. Neatrisinātas izvēles nav jāignorē.

Kā vēlāk atjaunināt skriptu

  1. Saņemiet no īpašnieka jaunāko uzstādīšanas ZIP failu un atpakojiet to.
  2. Pārbaudiet, ka izmantojat jauno failu, nevis veco kopiju Downloads mapē.
  3. Ja importēšanas laikā Scriptable piedāvā aizstāt esošo TURIBA NEXT, izvēlieties aizstāšanu tikai pēc nosaukuma pārbaudes.
  4. Ja aizstāšana netiek piedāvāta, atveriet esošo TURIBA NEXT redaktorā, atlasiet visu veco kodu un aizstājiet to ar visu jauno kodu no jaunā HTML teksta lauka vai JS faila. Saglabājiet to pašu skripta nosaukumu. Jauno kodu nedrīkst pielīmēt vecā koda beigās.
  5. Saglabājiet ar Done, vienreiz palaidiet skriptu un pārbaudiet grafiku.
  6. Atgriezieties logrīkā. Ja izveidojāt jaunu skriptu ar citu nosaukumu, atveriet Edit Widget → Script un izvēlieties pareizo skriptu.

Parastam atjauninājumam nav jādzēš Scriptable vai projekta dati. Iestatījumi un kešatmiņa glabājas atsevišķi. Ja konkrētam nākamam laidienam būs īpašas migrācijas darbības, īpašnieks tās norādīs atsevišķi. Šim komplektam datu atiestatīšana nav vajadzīga.

TURĪBA NEXT — install on your iPhone, step by step

You need only an iPhone, an internet connection, Scriptable and the supplied file. You do not need a computer or programming skills.

What this installs

TURĪBA NEXT shows your Turība group timetable on your iPhone Home Screen. Choose a Small square widget or a Medium rectangular widget. The interface supports English, Latvian and Russian, with light/dark appearance. Class reminders are optional and OFF initially.

Scriptable is the app that runs the widget. Keep it installed. A script is a ready-made program stored in a file: you do not have to understand or edit its code.

Have these ready:

  • an iPhone with internet access;
  • the Scriptable app;
  • TURIBA-NEXT-iPhone.zip, or the separate TURIBA NEXT.js file;
  • your own study group code, for example TVL2D1. This is an example, not the group everyone should choose.

Button names and positions can differ slightly with your iOS version and language. The instructions describe the expected result after each stage so that you can check your progress.

Step 1. Install Scriptable

  1. On your iPhone, open Scriptable in the App Store. If the link does not open, search the App Store for Scriptable, by Simon B. Støvring.
  2. Tap Get, or the cloud icon if you installed it before.
  3. If your phone requests Face ID, Touch ID or your usual App Store confirmation, approve the download as you would for another app.
  4. Wait for installation, then tap Open.
  5. Complete any introductory screens. You do not need to run the example scripts that come with Scriptable.
  6. Return to this guide.

You should now have: Scriptable installed and able to open. TURĪBA NEXT does not require additional developer tools or a university account.

Step 2. Save the kit to your iPhone

Choose one option: A or B.

Option A. You are downloading from GitHub

  1. Open this page in Safari on your iPhone. If a messaging app opened a small built-in browser, use its Open in Safari action, often under … or Share.
  2. Sign in to a GitHub account with access if requested. If you have no repository access, use option B and ask the owner to send the archive.
  3. Tap Download the complete iPhone kit near the top of this guide.
  4. If Safari asks whether to download the file, tap Download.
  5. If GitHub shows the archive's file page instead, find the downward arrow Download raw file, sometimes inside …, and tap it. Do not use Code → Download ZIP on the repository homepage: that downloads the entire development project.
  6. Open Apple's Files app, which has a folder icon. If you cannot find it, swipe down on the Home Screen and search for Files.
  7. Open Browse and locate Downloads. Depending on your Safari settings, Downloads may be in iCloud Drive or On My iPhone.
  8. Find TURIBA-NEXT-iPhone.zip. If repeated downloads added a number to its name, use the most recent copy.

You should now have: the ZIP visible inside Files.

Option B. A friend sent the archive by message or AirDrop

  1. Download the actual file, named TURIBA-NEXT-iPhone.zip. A screenshot or a link to the private repository is not the installation file.
  2. Open Share, usually a square with an upward arrow. In a messaging app, first open the file or its … menu if necessary.
  3. Select Save to Files.
  4. Choose a folder you can find again, such as On My iPhone → Downloads, and tap Save. Another folder is fine if Downloads is not present.
  5. For AirDrop, save the received archive to Files if your phone offers an open/save choice. The exact screen depends on iOS.
  6. Open Files and go to the folder you selected.

You should now have: the ZIP inside Files. No GitHub login is required.

Step 3. Extract the ZIP

  1. In Files, tap TURIBA-NEXT-iPhone.zip once.
  2. A normal folder named TURIBA-NEXT-iPhone should appear beside it. iOS may add a number if the folder already existed.
  3. Open the new folder.
  4. You will find the script and instructions:
FileWhat it is for
TURIBA NEXT.jsThe widget program. This is the only file to add to Scriptable.
INSTALL.htmlThe phone-friendly guide. Open it and choose English, Latvian or Russian.
INSTALL_EN.mdThe complete English guide as ordinary text if HTML viewing is unavailable.

If your phone only shows a preview of the ZIP, return to Files and tap the archive there. Another option is to hold the ZIP and choose Uncompress if that action appears.

If you received only TURIBA NEXT.js, there is nothing to extract. Continue with step 4. Do not try to import the ZIP itself as a Scriptable program.

You should now have: the separate TURIBA NEXT.js file.

Step 4. Add the script to Scriptable

Try method A first. If your phone does not offer an import, use method B. Neither method requires changing the program.

Method A. Share the file

  1. In Files, touch and hold TURIBA NEXT.js.
  2. Choose Share.
  3. Look for Scriptable in the row of app icons. Swipe along the row or open More if necessary.
  4. Select Scriptable. If it offers to add, save or import a script, confirm that action.
  5. Name the script TURIBA NEXT. Use the same name when selecting it in widget settings later.
  6. If Scriptable only shows a list of other scripts, the new script does not appear, or Scriptable is missing from Share, use method B. Do not run a random example script from the list.
  7. Open Scriptable's Scripts screen and check that a TURIBA NEXT card is present.

The Share/import options vary with iOS and Scriptable versions. If they are unavailable, installation can still be completed by copying the ready-made text.

Method B. Copy the entire ready-made program

You are only moving existing text. You do not have to write or change any code.

  1. Open INSTALL.html from the kit. Find the Код / Kods / Script text section at the end of that file and expand it.
  2. Inside is a separate field containing the entire program. Touch and hold the text, choose Select All, then Copy. Copy the field's contents, not this guide or the section title.
  3. If HTML viewing or text selection does not work, try opening TURIBA NEXT.js as text and using Select All → Copy there. If you have GitHub access, another option is opening the .js file page, choosing Raw and copying its complete text. If none of these options works, ask the owner to help transfer the file; editing the program is not necessary.
  4. Open Scriptable and go to Scripts.
  5. Tap + at the upper right. This opens the editor for a new script: a large text area.
  6. If there is existing text, touch and hold it, use Select All, then Paste. If the editor is empty, tap inside and choose Paste.
  7. If iOS asks permission to paste from another app, approve the paste you just requested.
  8. Many lines will appear. This is normal. Do not remove lines, add quotation marks or insert the script's title into the program text.
  9. Open the script's name/settings, usually by tapping its title at the top of the editor; some versions use a nearby menu or settings button. If a separate Name field appears, edit that field rather than typing a name into the code.
  10. Set the name to TURIBA NEXT. Tap Done to leave the editor and confirm saving if the app asks.
  11. Return to Scripts and check that the card is named TURIBA NEXT. A card named Untitled Script can be renamed in its script settings.

You should now have: one TURIBA NEXT script containing the complete supplied program, not merely a text note or a file sitting in Downloads.

Step 5. Run the script and choose your group

  1. In Scriptable, tap the TURIBA NEXT card. From the editor you can instead use the triangular ▶ run button.
  2. On first launch, choose English if you want the button names used in this guide. You can change the language later.
  3. Tap the group field and enter your own code, for example TVL2D1.
  4. This example uses Latin letters T V L, the digit 2, Latin D, and the digit 1. Do not add quotation marks, the word “group” or spaces inside the code. An English keyboard helps avoid look-alike letters.
  5. If your group is different, use its code. Ask your group representative, check your study materials or find it in the public Turība timetable. Do not choose TVL2D1 just because it appears in this guide.
  6. Tap Save and wait for the timetable to load. Keep the app open during this initial request.
  7. The TURĪBA NEXT settings menu should appear with your group. If the week's timetable has not been published, you may receive a message saying so. This does not confirm a day off.
  8. Open Electives & subgroups if relevant to your group.
  9. Select only your own courses and subgroups. ✓ means selected; tapping again deselects it. Use Cancel to leave this list: changes you already made have been saved.
  10. If no choices are found, they are absent from the loaded weeks. Do not choose an unrelated course just to fill the list. Personal BATIS details may not exist in the public source.
  11. In Appearance, choose System to follow your iPhone, or force Light or Dark.
  12. Leave class reminders OFF for now if you only want the widget. They are not required for timetable display.

You should now have: a saved group, language and study choices. You do not need to enter a BATIS password.

Step 6. Add a Home Screen widget

Configuring the script does not automatically create a Home Screen widget. Add it separately:

  1. Go to the iPhone Home Screen, where your app icons are. Do not begin with the Lock Screen.
  2. Touch and hold an empty area between icons until the icons jiggle.
  3. Tap Edit → Add Widget. Some iOS versions show a + button directly instead; use it.
  4. Search for Scriptable, not TURIBA NEXT. The widget belongs to the Scriptable app.
  5. Select Scriptable in the results.
  6. Swipe through sizes. Small is a square with the subject, large room code and start time. Medium is a rectangle with a separate room panel and the following lesson.
  7. Choose Small or Medium. Large and Lock Screen widget families are not intended for this kit.
  8. Tap Add Widget, then Done.
  9. Touch and hold the widget you just added.
  10. Choose Edit Widget.
  11. Tap the Script field.
  12. Choose TURIBA NEXT, the script installed in step 4, rather than a Scriptable example.
  13. Leave Parameter empty for the first widget. Your group is already stored in settings.
  14. If When Interacting is available, select Run Script.
  15. Tap outside the configuration panel to close it. Allow your phone a little time to show the timetable.
  16. For both sizes, repeat these steps and select the same TURIBA NEXT script in each widget.

You should now see: a subject and room on your Home Screen, with an additional next-lesson row in Medium. If the widget still asks you to select a script, repeat steps 9–12.

Step 7. Check your result

Open the public timetable for the same group and week, then compare the subject, date, start/end times and room.

The next class may be on another day. Missing rooms remain marked as not supplied; the widget does not invent them. All lesson times refer to Europe/Riga, even if your iPhone is currently in another country.

Outside class hours, the widget may show the next known lesson or a completed/no-selected-classes status. An unpublished or unavailable week does not establish that there are no classes.

The essential installation is now complete. You may close Scriptable, but keep the app installed or its widget cannot work.

Open settings later

Open Scriptable and tap TURIBA NEXT. Tapping the widget also opens the script when configured to run it.

Change group, language, appearance, choices or reminders there. Sync now manually requests the latest timetable. A change on the university website becomes known to the script only after a successful refresh.

Optional class reminders

You may skip this section if the widget alone is enough.

  1. Open Scriptable → TURIBA NEXT → Class reminders.
  2. Choose On.
  3. Choose 10 minutes as the standard interval, or 5, 15 or 30.
  4. If iOS asks for Scriptable notification permission, allow it if you want reminders.
  5. If there is no eligible future class yet, permission may not be requested immediately. No fake notification is created just to trigger the prompt.
  6. To disable, return to this setting and choose Off. Pending TURĪBA NEXT reminders are removed without globally removing other scripts' notifications.

Reminders apply only to the main group saved in settings. The planner considers up to seven days and 32 reminders per plan. Refresh regularly. Focus modes, notification-preview settings and iOS delivery rules can affect what you see.

If you previously denied permission, search iPhone Settings for Scriptable's notification settings and enable them if desired. The exact menu path depends on iOS. The widget still works when permission is denied.

Widgets for different groups

  1. Set up your main group normally.
  2. Add another Scriptable widget and select TURIBA NEXT again.
  3. Enter the other group's code, for example CSA1D1, into that widget's Parameter field.
  4. Tap outside the panel. That instance loads the other group without changing the main group.

For another group's course choices, temporarily select it as the main group in the script, configure its choices, then restore your previous main group. Changing the main group removes its old pending reminders, which matters if reminders are enabled.

Update without losing settings

  1. Obtain the new script from the owner, rather than reopening an older downloaded archive.
  2. Copy the entire new program using method 4B.
  3. In Scriptable, open the editor for the existing TURIBA NEXT script, normally through … on its card. Do not create a second script for an ordinary update.
  4. Select all old code and paste the new code in its place. Keep the script's existing name.
  5. Leave the editor with saving, run the script again and select Sync now.
  6. Check both widgets. Settings and cache are stored separately and should not be deleted for a routine update.

If you accidentally imported a duplicate, first select the intended script in the widget's settings. Ask the owner for help removing the duplicate if uncertain; do not delete everything.

Common problems

GitHub says 404 or Not Found

Your account may lack access to the private repository. Ask for TURIBA-NEXT-iPhone.zip as a file. There is no need to make the source repository public.

I cannot find the downloaded archive

In Files → Browse, check Downloads under iCloud Drive and On My iPhone. Also look in Recents or search Files for TURIBA.

The file contains lots of unfamiliar text

That is the program. Add it to Scriptable using step 4. Do not paste it into Notes, the Safari address/search bar or the group-code field.

The script is missing from the widget's Script list

Open Scriptable and check that the TURIBA NEXT card exists. Run it at least once, then return to Edit Widget → Script. If no card exists, repeat step 4.

There is no TURIBA NEXT in the widget search

Search for Scriptable. Select TURIBA NEXT later inside the added widget's settings.

TVL2D1 or another group will not load

Check the keyboard, spelling and spaces. Confirm that the group exists in the public timetable and the website is reachable. Your own code may differ from the example. If the code is correct and the public source works, send the owner the displayed error rather than altering the program.

Offline, old timetable or stale-data warning

Restore internet access, run the script and use Sync now. Last valid data is kept when requests fail. Until the warning clears, check important details against the public timetable.

The status does not change at an exact minute

iOS chooses when the widget refreshes. An exact ten-minute countdown transition or second-by-second update is not guaranteed. Run the script and refresh manually when you need a fresh check.

An error shows Build, Stage, Code, Message or Cause

Take a screenshot and send it to the owner with the action you took before the error. Do not reset settings or reinstall everything before the cause is understood. Diagnostics stay on the phone and are not automatically uploaded.

Remove a widget or erase project data

To remove only the Home Screen widget, hold it and choose Remove Widget. This does not erase the script's settings.

To erase this project's settings/cache and pending reminders, run the script and use Delete My Data. Confirm only if you want to start setup again. Do not erase Scriptable's entire documents folder; it may contain other projects.

Share with a friend

Send TURIBA-NEXT-iPhone.zip itself, for example through AirDrop or as a messaging attachment. A screenshot or private GitHub link is not a substitute for the file. Your friend saves it to Files, extracts it, opens INSTALL.html and chooses a language.

Each friend selects their own group and courses. Do not send your personal settings or cache. Friends installing from the archive do not need source-repository access. Shortcuts automation is optional and is not needed for the first test; steps 1–7 are enough.

What to report after testing

Tell the owner your iPhone model, iOS version, widget size, group and what worked. For a problem, include a screenshot and what you pressed immediately before it. Hide unrelated personal notifications or other private information in screenshots if needed.
